# TinyNote

Fast, private, offline notepad. 100% client-side (HTML/CSS/JS). Open `index.html` in any modern browser.

## Features
- Rich text editor: bold, italic, underline, strike, colors, highlight, font family, size, headings, lists, quotes, code, hr, links, images, tables, checklists.
- Auto-save to localStorage on every keystroke.
- Sidebar: search, filter (All / Pinned / Favorite / Trash), sort, pin, favorite.
- 4 themes: Light, Dark, AMOLED, Sepia (glassmorphism).
- Import: drag-and-drop `.txt`, `.md`, `.html`, `.json` anywhere on the page.
- Export: TXT, Markdown, HTML, PDF (via print), JSON.
- Floating buttons (bottom-right): Copy all text, Delete all text.
- Command palette (Ctrl+K), keyboard shortcuts.
- Focus mode, Zen mode, print.
- Fully mobile-responsive with slide-in sidebar and bottom-sheet menu.

## Shortcuts
- Ctrl+K — Command palette
- Ctrl+N — New note
- Ctrl+S — Save
- Ctrl+P — Pin
- Ctrl+B/I/U — Bold/Italic/Underline
- F11 — Zen mode
- Esc — Close overlays
